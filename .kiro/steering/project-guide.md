# Правила проекта Vocal School

## Стек технологий
- Next.js 14, TypeScript, Tailwind CSS
- Prisma ORM с PostgreSQL
- API Routes для backend

## Структура проекта
- `/src/app` — Next.js pages
- `/src/components` — React компоненты
- `/src/lib` — утилиты и helpers
- `/prisma` — схема БД

## Соглашения
- Используем kebab-case для файлов
- PascalCase для компонентов
- camelCase для функций/переменных
- Все компоненты TypeScript с полной типизацией
